📋 如何填充您自己的图片和注释

1. 找到上面 <script> 里的 pairs 数组。

2. 每个花括号 { } 代表一组：
  • before : 修改前图片的URL
  • after : 修改后图片的URL
  • note : 这对图片的描述文字

3. 一共九组，您可以直接替换示例中的URL（包含占位图）。图片建议使用稳定图床，避免外链失效。

4. 下方的“碎碎念”区域可在 afterwordHTML 常量中修改（支持HTML）。完成后刷新页面即可。

🔍 提示：移动端会自动堆叠为单列，方便查看。
